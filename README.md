# Motopark Toruń – Assetto Corsa

Darmowy tor do Assetto Corsa z Custom Shaders Patch: **Motopark Toruń**, odtworzony od zera ze skanu laserowego (lidar) i zdjęć lotniczych GUGiK.

**Pobierz: [motopark_torun_1.0.1.zip](https://github.com/Gustaw0000/motopark-torun-download/releases/download/v1.0.1/motopark_torun_1.0.1.zip)** (113 MB)

Instalacja: przeciągnij zip do Content Managera i kliknij Install. Najlepiej z aktualnym CSP.

- Strona moda: [OverTake.gg](https://www.overtake.gg/downloads/motopark-toru%C5%84.87528/)
- Discord i otwarty serwer drift „Driftownia”: [discord.gg/xyJ3ahpUpn](https://discord.gg/xyJ3ahpUpn)
